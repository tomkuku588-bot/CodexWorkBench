# CodeAI 工作台合规文档

这个仓库用于部署 CodeAI 工作台的公开合规页面，包含隐私政策与用户协议，并支持中文 / English 页面切换。

## 文件

- `index.html`：合规文档入口页
- `privacy-policy.html`：隐私政策
- `user-agreement.html`：用户协议
- `assets/site.css`：公共样式
- `assets/lang.js`：中英文切换逻辑，默认跟随浏览器语言并记住用户选择
- `scripts/verify-site.ps1`：静态页面验证脚本
- `.nojekyll`：禁用 Jekyll 处理，确保静态文件原样发布
